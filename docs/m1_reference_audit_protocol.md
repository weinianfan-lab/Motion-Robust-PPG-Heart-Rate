# M1 固定时间规则的独立参考诊断

记录日期：2026-10-25。本文件在读取真实受试者的标签值前登记，仅用于检查官方数据，不训练模型、不替换原标签。

## 数据身份与单位

只有完成官方 HTTPS 获取、服务器长度／校验值核对与 ZIP CRC 检查后，才读取提取的本地 pickle。每次只处理一位受试者，记录原文件 SHA-256 与完整字段结构。原始文件只读。

`rpeaks` 的单位首先由官方说明、数组类型、整数性、极值与 ECG 长度判断；不能用与 label 的吻合程度选择单位。官方 README 文本称 ECG 索引，ECG 率为 700 Hz。如果实际值为非整数、且时间范围明显符合秒，记录文档与实现的差异并据此开展明确标记的诊断；若范围无法消除单位歧义，停止转换。

## 固定窗口和计数检查

固定候选时间原点 t0=0，窗 `[2k,2k+8)`，不搜索正负偏移，不改变 8/2 秒协议。分别报告每一模态的长度、物理时长、完整窗口数、最后完整窗、残余样本数、原标签数量与活动长度。

报告以下两种明确的终止计数，供解释数据结构；不按评价误差选择：

- 包含恰好在记录终点结束的完整窗：`start + window <= N`。
- 排除恰好在记录终点结束的窗：`start + window < N`。

还记录原标签覆盖结束后是否有额外完整信号窗、部分尾窗，以及标签是否超出任一输入。任何差异保留数量与索引，不能静默截断。

## 独立 R 峰诊断

主要诊断只使用原数据中已有且人工检查过的 R 峰。对于固定 `[2k,2k+8)`，取窗内 R 峰的相邻 RR，计算 `mean(60/RR)`。不重新检测 ECG、不平滑／筛选 RR、不裁剪 BPM、不将诊断结果写回 label。

这是对“窗内瞬时 HR 均值”的一种明确数值解释。原始文档没有给出跨边界 RR 的归属、插值／平滑和生成代码，因此即使不一致，也不能立即判断原标签错误；即使吻合，也不能冒称已找到作者实现。诊断输出包含全窗与首／尾窗残差、可计算数量及不可计算原因，不只展示有利片段。

允许额外列出右端点／左端点／中点归属的预先定义数值诊断，均使用同一 t0=0，不能择优后包装成官方规则。任何新增数值解释须先记录到本文件，不进行 label-driven 时间偏移搜索。

## 结论层级与门槛

分别报告：官方文本事实、实际数据结构、固定假设下的数学核查、尚未核定的生成细节。论文报告的 64,697 个标注窗仅作完整性总数对照。

本诊断本身不自动解除 `label_origin_unverified` 或 `tail_rule_unverified`。要发布可用于后续正式评价的版本化适配器，需独立审查来源与时间依据；证据不足继续 BLOCKED。实际审计执行完成与 M1 对齐门槛通过是不同状态。

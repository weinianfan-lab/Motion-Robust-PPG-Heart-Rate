# 求职展示发布候选边界

2026-10-25 用户已明确授权原创代码使用 MIT 许可证、创建公开 GitHub 仓库及上传经过审核的展示包。授权范围仅限下述白名单。

`scripts/audit_publication.py` 生成显式逐文件白名单及哈希，列入原创代码、必要配置、合成测试、固定受试者划分、专业 README、当前工程合同和允许的汇总图表/指标。不要直接上传整个工作目录；历史溯源文档和旧草稿留在原处，不因未列入白名单而删除。

不列入：原始信号、pickle、窗口缓存、逐窗真实预测、checkpoint/ONNX 权重、完整运行日志、作者邮件包、个人信息、本机绝对路径、未经审核的图表/PDF。`docs/assets/` 的真实数据图仅含模型误差柱状图、按受试者汇总误差图和误差分布，没有真实逐窗曲线或原始信号；另可放明确标注 SYNTHETIC DATA 的自生成信号演示图。合成 demo 在本地可复跑。

原创代码采用 [MIT](../LICENSE)，第三方范围见 [许可说明](../THIRD_PARTY_NOTICES.md)；数据与论文许可不由代码许可证覆盖。UCI 与作者页面的使用说明差异记录在 data_policy.md，不把展示给公司或可下载误解为已取得商业再分发权利。默认不分发数据、模型或受试者派生明细。

CI 文件仅提供可运行的基础检查配置，目前未在 GitHub 执行；Windows 本地的真实验证与 Linux CI 计划分别报告，不能因有 YAML 就声称多平台通过。身份信息从候选包元数据中移除；所有个人配置保留在本地忽略目录。
